# سوبر ماركت الحمد — الموقع والمخزون

موقع عربي كامل (RTL) على GitHub Pages:
- **واجهة المتجر** `index.html`: كل المنتجات بالصور والأسعار وحالة المخزون، بحث وأقسام، سلة شراء.
- **خدمة التوصيل**: نموذج طلب (اسم/موبايل/عنوان/منطقة برسوم توصيل مختلفة) والدفع عند الاستلام، والطلب يتبعت واتساب للمحل.
- **إدارة المخزون** `admin.html`: تعديل السعر والكمية، تنبيه النواقص والنافد، إجمالي قيمة المخزون، تصدير CSV يفتح في إكسل.
- **الداتا الكاملة**: `data/products.json` و `products.js` — 156 منتجًا في 12 قسمًا من السوق المصري (الاسم، الماركة، الوحدة، السعر، سعر العرض، المخزون، SKU، الباركود، الصورة).

## قبل التشغيل الفعلي
1. عدّل رقم واتساب المحل في `index.html` عند `CONFIG.whatsapp` (دلوقتي رقم مؤقت).
2. الأسعار استرشادية بتاريخ 2026-11-21 — راجعها وعدّلها من صفحة المخزون أو من ملف الداتا.
3. تفعيل النشر: من إعدادات الريبو على GitHub ← Pages ← اختر فرع `main` — هيظهر الموقع على:
   `https://kingmanz2025-byte.github.io/alhamd-supermarket/`

## إضافة منتجات
ضيف سطر جديد في `data/products.json` و `products.js` بنفس الحقول، أو ابعت القايمة لمساعدك وهو يضيفها.
